# 🌦️ WeatherNova

A responsive weather forecast web application built using **HTML, CSS, and Vanilla JavaScript**, integrated with the **OpenWeather API** to provide real-time weather updates and a 5-day forecast.

🔗 Live Demo: https://weathernova-nancy.netlify.app/

## 🚀 Features

* 🌍 Search weather by city name
* 🌡️ Real-time temperature display (°C / °F converter)
* 📅 Current date and time display
* 💨 Wind speed, humidity, pressure, cloud coverage
* 🌅 Sunrise and sunset timing - based on the location
* 🌧️ Rain volume detection
* 📊 5-Day weather forecast
* 🌙 Dark / Light mode with persistent theme (localStorage)
* 🎨 Dynamic background change based on weather condition

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3 (Grid + Flexbox)**
*  JavaScript (ES6)
* **OpenWeather API**
* **Netlify (Deployment)**

---

## ⚙️ How It Works

1. User enters a city name.
2. App fetches real-time weather data from OpenWeather API.
3. Additional API call retrieves forecast data.
4. DOM updates dynamically without page reload.
5. Theme preference is stored using localStorage.
